🧟 State of GitHub Spam 🔌 API

🔌 Farm Ledger API

Machine-readable, hourly-updated data behind the State of GitHub Spam investigation. Free, no key, no rate limit (static files). CORS-enabled for browser use.

Endpoints

EndpointWhat it is
api/farms.jsonLive farm actors + owners for the current hour (actor → hours seen, last seen). ~2.8 MB.
data/snapshot.jsonFull live snapshot: hottest repos, bot watch, spam %, demoted, farm probe.
data/history/2026-08-12-9.jsonPer-hour snapshots, gapless back to hour 6 (8/11). Browse via data/history/index.json.
data/digest.xmlRSS feed — 10 latest hourly digests.

Example

curl https://github-pulse.surge.sh/api/farms.json | jq 'to_entries[:3]'

  "920513": { "hours": ["2026-08-11-1", ...], "lastSeen": "2026-08-12-9" },
  ...

Field notes

  • What's a farm actor? An account behind a repo flagged push-bot (auto-generated name + zero human signal, or ≥25 zero-human pushes/hr). Repos rotate — accounts persist. That's the durable signal.
  • Confirmed vs fresh: an entry demotes other repos only after being seen in ≥2 distinct hours (repeat offender). Fresh entries are listed but inert.
  • False-positive guard: shared platform bots (github-actions[bot], dependabot, any *[bot]) are scrubbed — farms launder pushes through Actions, and a shared bot must never blacklist the repos it touches.
  • Adaptation tracking: the farms read the site and adapt (push volume 40→30→25→24/hr; now self-PRs to fake human signal). Detection is profile-based, not threshold-based.
